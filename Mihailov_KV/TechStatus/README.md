# ТехСтатус

**Учебная информационная система учёта и контроля доступности оборудования.**

Локальное веб-приложение на Python. Помогает учитывать технику в аудиториях,
просматривать статусы **«Доступно»** и **«Занято»**, оформлять выдачу и возврат,
находить оборудование и смотреть журнал действий.

## Запуск

Требуется **Python 3.10 или новее**. Сторонних библиотек устанавливать не нужно.

1. Откройте терминал в папке проекта.
2. По желанию создайте демонстрационные данные:
   ```bash
   python demo_data.py
   ```
3. Запустите программу:
   ```bash
   python run.py
   ```
4. Откройте в браузере **http://127.0.0.1:8000**.
5. Для остановки нажмите `Ctrl+C` в терминале.

Данные сохраняются в файле `data/techstatus.sqlite3`, который создается автоматически
и не должен загружаться в GitHub. Для чистого старта остановите приложение и удалите
этот файл (операция удаляет локальные записи).

## Проверка логики

```bash
python -m unittest discover -s tests -v
```

## Возможности версии 0.1

- Реестр инвентарных единиц с поиском и фильтрами.
- Добавление, изменение и удаление доступного оборудования.
- Выдача с указанием получателя; запрет повторной выдачи.
- Возврат; запрет повторного возврата.
- Подсчет доступных и занятых единиц.
- Журнал добавления, изменений, выдачи, возврата и удаления.
- Хранение данных в локальной базе SQLite.

## Ограничения учебного прототипа

- Приложение предназначено для одного ответственного пользователя на одном компьютере;
  нет регистрации, разграничения прав и синхронизации между компьютерами.
- Сервер запускается только на `127.0.0.1`, не предназначен для публикации в интернете.
- Оборудование предполагается штучным: одна карточка — одна единица.
- Не предусмотрены штрихкоды, автоматическая инвентаризация и уведомления.
